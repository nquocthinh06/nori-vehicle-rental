# Mô hình Bảo mật Hệ thống Thanh toán — NORI Vehicle Rental

## 1. Các nguyên tắc bảo mật bắt buộc đã triển khai

| Nguy cơ bảo mật                                    | Biện pháp phòng vệ tại NORI                                                                                                                                                                                                              | Vị trí cài đặt                                                                                                                                                                                       |
| -------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Giả mạo Webhook (Webhook Spoofing)**             | Xác thực `Authorization: Apikey <SEPAY_WEBHOOK_SECRET>` bằng `timingSafeSecretCompare` sử dụng SHA-256 + `crypto.timingSafeEqual` (không rò rỉ độ dài bí mật). Từ chối `401` và ghi nhận `FAILED_SIGNATURE` vào `payment_events`.        | [`src/lib/payment-providers.ts`](../src/lib/payment-providers.ts), [`src/app/(frontend)/nori-api/payments/webhook/sepay/route.ts`](<../src/app/(frontend)/nori-api/payments/webhook/sepay/route.ts>) |
| **Chỉnh sửa số tiền từ Client (Amount Tampering)** | `POST /nori-api/payments/create` **không nhận** tham số `amount` từ Client. Mọi số tiền thanh toán đều được Backend tính trực tiếp từ `bookings`, `payments`, `refunds` và `nori-site`.                                                  | [`src/lib/payment-service.ts`](../src/lib/payment-service.ts)                                                                                                                                        |
| **Truy cập trái phép đơn người khác (IDOR)**       | Mọi API thanh toán khách hàng đều gọi `appAuth.requireCustomer` và đối chiếu `relationId(booking.customer) === user.id`. Khách hàng B nhận ngay `403 FORBIDDEN`.                                                                         | `src/app/(frontend)/nori-api/payments/*`                                                                                                                                                             |
| **Leo thang quyền Admin / RBAC**                   | Các API quản trị yêu cầu `requireAdmin({ permission: ['payments', 'read'                                                                                                                                                                 | 'update'] })`hoặc`settings.update`. Nhân viên chỉ có quyền xem (`read`) bị chặn `403` khi xác nhận thu hoặc hoàn tiền.                                                                               | `src/app/(frontend)/nori-api/dashboard/payments/*` |
| **Xử lý trùng Webhook / Race Condition**           | Khóa tuần tự hóa `withBookingWriteLock` kết hợp kiểm tra trùng `eventId` (UNIQUE INDEX trên `payment_events.event_id`) và trùng `externalTransactionId`.                                                                                 | [`src/lib/payment-service.ts`](../src/lib/payment-service.ts)                                                                                                                                        |
| **Rò rỉ khóa bí mật vào Client Bundle hoặc Logs**  | `scripts/static-lint.mjs` chặn `SEPAY_API_KEY`, `SEPAY_SECRET_KEY`, `SEPAY_WEBHOOK_SECRET`, `PAYLOAD_SECRET`, `NORI_SESSION_SECRET` trong mọi file `'use client'`. `sanitizeWebhookPayload` lọc sạch mọi khóa nhạy cảm trước khi lưu DB. | [`scripts/static-lint.mjs`](../scripts/static-lint.mjs), [`src/lib/payment-providers.ts`](../src/lib/payment-providers.ts)                                                                           |
| **CSRF & Cross-Origin Mutation**                   | Toàn bộ route `POST`/`PATCH`/`PUT`/`DELETE` dưới `/nori-api/` (ngoại trừ Webhook bên thứ 3 xác thực bằng Apikey) đều bắt buộc gọi `assertOrigin(request)` và `assertRateLimit`.                                                          | [`scripts/static-lint.mjs`](../scripts/static-lint.mjs), `src/lib/api-utils.ts`                                                                                                                      |
| **Kích hoạt nhầm Production**                      | Chế độ `PRODUCTION` yêu cầu đồng thời `PAYMENT_MODE=production`, `PAYMENT_ENABLED=true`, `PAYMENT_PRODUCTION_APPROVED=true` và đủ khóa SePay Production; mặc định luôn khóa (`503 PRODUCTION_NOT_ACTIVATED`).                            | [`src/lib/payment-providers.ts`](../src/lib/payment-providers.ts), [`src/lib/rental-rules.ts`](../src/lib/rental-rules.ts)                                                                           |
| **CSV Formula Injection**                          | `escapeCsvCell` tự động trung hòa các ô bắt đầu bằng `=`, `+`, `-`, `@`, `\t`, `\r` khi xuất CSV giao dịch và báo cáo tài chính.                                                                                                         | [`src/app/(frontend)/nori-api/dashboard/export/route.ts`](<../src/app/(frontend)/nori-api/dashboard/export/route.ts>)                                                                                |
| **XSS / SQL Injection**                            | Toàn bộ truy vấn SQLite sử dụng Prepared Statements tham số hóa / Payload Local API; React tự động escape toàn bộ chuỗi hiển thị; cấm tuyệt đối `dangerouslySetInnerHTML`.                                                               | Toàn bộ codebase                                                                                                                                                                                     |
