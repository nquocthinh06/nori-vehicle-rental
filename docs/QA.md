## Playwright E2E coverage (42 passing tests)

- **All 14 routes** (`/`, `/vehicles`, `/vehicles/toyota-fortuner`, `/vehicles/honda-pcx`, `/vehicles/ford-ranger-raptor`, `/about`, `/support`, `/login`, `/register`, `/account`, `/my-bookings`, `/checkout`, `/dashboard`, `/design-system`): HTTP `200`, single `<main> <h1>`, zero `pageerror`, zero horizontal overflow, every visible `<img>` decoded with `naturalWidth > 0`.
- **Navigation & Search**: hero carousel manual paging, keyboard mega menu + Escape focus restoration, home search (`PICKUP` -> 4 models; prefilled dates -> live rental quote breakdown on `/vehicles/toyota-fortuner`).
- **Catalogue Filters, Search & Pagination**: `20` total models, `12` per page + `Trang 1 / 2` pagination, multi-token & unaccented Vietnamese search (`"xe dien"` -> `VinFast VF 8` & `VinFast Evo200`), category/brand/price filtering, grid/list layout switching, A–Z Vietnamese sort, empty state & reset.
- **Detail Gallery & Availability Calendar**: honest missing interior fallback (`Honda PCX`), real interior/engine photos (`Toyota Fortuner`), Lightbox keyboard/focus restoration, 6-tab ARIA panel switching, non-wrapping 2-digit day cells (`white-space: nowrap`, height `<= 48px`) on both `1280px` desktop and `375px` mobile.
- **Security & Auth Guards**: unsigned `POST /nori-api/revalidate` -> `401`; unauthenticated `/nori-api/bookings` (`401`), `/nori-api/inquiries` (`401`), `/nori-api/dashboard` (`403`); role injection on `/nori-api/auth/register` -> `400`; buy consultation auth gate.
- **Full End-to-End Customer Lifecycle**: registration -> profile update -> `/vehicles/toyota-fortuner` live quote -> `/checkout` transaction-locked booking creation -> `/my-bookings` verification & cancellation (releasing calendar slots) -> consultation inquiry -> `/account` verification -> logout & re-login.
- **Accessibility, Resilience & Responsive Mobile**: loading/disabled/dialog focus states (`/design-system`), network failure input retention (`/login`), long unbroken string overflow defense (`375px`), 9 routes at `375px` mobile, and `prefers-reduced-motion: reduce`.

## Remaining gaps / known limits

1. **DEMO fleet vs real commercial inventory**: All 21 seeded vehicles are flagged `isDemo: true` with benchmark pricing and synthetic ODO/maintenance records for end-to-end demonstration; an operator must archive/deactivate DEMO records and enter verified real fleet units via `/admin` before commercial launch.
2. **Offline payments**: Checkout, deposit, and sales inquiry deposits remain explicitly offline (no payment gateway, card processing, or automated bank webhook).
3. **Authentication scope**: No automated CMS Admin Playwright login test was executed in E2E (because `admins` uses platform/CMS auth and `./nori.db` starts with 0 local CMS admin rows), so admin transition buttons in `/dashboard` are verified at compile/unit-test/API boundary level rather than with an authenticated admin E2E browser session.
4. **Concurrency & review UI post-completion**: Booking overlap prevention via SQLite `rental-days` unique keys was exercised through sequential create/cancel E2E runs (`bookings: 0` cleanly left in DB); simultaneous parallel burst conflict tests and browser posting to `/nori-api/reviews` via a `COMPLETED` booking remain untested in E2E.
5. **External brand portals**: Where manufacturer portals block automated scraping or lack permissive reuse licenses, verified Wikimedia Commons photographs (`CC0`, `CC BY`, `CC BY-SA`) were downloaded locally (`public/seed-media/*.jpg`) with explicit source attribution rather than hotlinking or inventing images.
6. **Production deployment target**: `next.config.ts` specifies `output: 'standalone'` and local verification used `next dev` (for all 42 Playwright tests) + `pnpm build` + `pnpm start` HTTP 200 smoke checks; managed `figma make verify-deploy` should still be executed inside the Figma Make deployment runtime if publishing there.
