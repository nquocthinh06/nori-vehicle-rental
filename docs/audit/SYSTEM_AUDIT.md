## 4. Hiện trạng sau Remediation & Khoảng trống Go-Live

| Phân loại                                       | Chi tiết                                                                                                                                                                                                                                                                                 | Ghi chú kiểm toán                                                                                 |
| :---------------------------------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :------------------------------------------------------------------------------------------------ |
| **Hoàn thiện & kiểm chứng trên isolated build** | Toàn bộ luồng thuê xe, sửa đơn, khóa lạc quan `expectedRevision`, thanh toán/hủy đơn nhất quán, RBAC 3 tầng + quyền `publish`, tách seed demo `NORI_DISABLE_DEMO_SEED`, webhook fallback `notifications.ts`, `/nori-api/health`, bảo mật headers & tối ưu `/nori-api/fleet` (`606 RPS`). | Đã xác minh qua `247/247` Unit + `92/92` Playwright E2E + `7/7` Browser UAT + Edge Cross-Browser. |
| **Ngoài phạm vi MVP ngoại tuyến**               | Cổng thanh toán thẻ tự động, gửi SMS/Email thật (dùng in-app + optional webhook), cước theo giờ, e-Contract.                                                                                                                                                                             | Hiển thị minh bạch trong UI & `DEPLOYMENT_READINESS.md`.                                          |
